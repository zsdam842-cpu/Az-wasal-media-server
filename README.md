# Wasal Server

Backend server for the **وصال (Wasal)** Android messaging application.

## Technology

- Node.js
- TypeScript
- Express
- Socket.io
- PostgreSQL
- Object Storage
- WebRTC
- Coturn

## Features

The server will support:

- User accounts
- Authentication
- Private conversations
- Messaging
- Images and videos
- Files
- Voice messages
- Stickers
- Message editing
- Message deletion
- Message forwarding
- Replies
- Reactions
- Read receipts
- Voice calls
- Video calls
- Polls
- Events
- Location sharing
- Contact sharing
